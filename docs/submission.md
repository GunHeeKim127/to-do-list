# 제출문 초안

## ① AI에게 맡긴 일
- 기존 TaskDiary의 구조를 최대한 유지하면서 Supabase CRUD를 함수(`func`)로 분리했습니다.
- 계획/계획 History/실행 기록을 위한 데이터 구조와 UI를 추가했습니다.
- 검색·필터·정렬 및 돌아보기 집계를 추가했습니다.
- 완료 기록의 DB 차원 중복 방지를 위해 idempotency key와 DB Unique Constraint/RPC를 적용했습니다.
- JSON Export와 로그인 미지원 공개 경고 문구를 추가했습니다.

## ② 내가 직접 판단한 일
- 기존 화면과 컴포넌트 구조를 유지하고 필요한 기능을 추가하는 방향을 선택했습니다.
- 계획과 할 일을 별도 개념으로 두고 `plan_id` 외래키로 연결했습니다.
- 삭제는 즉시 물리 삭제하지 않고 `deleted_at`을 사용해 복원을 가능하게 했습니다.
- 지연 기준은 요구사항에 맞춰 `미완료 AND 마감일 < Asia/Seoul 오늘`로 정의했습니다.

## ③ AI 제안을 따르지 않은 일
- 기존 UI를 전면 재작성하지 않고 현재 프로젝트의 컴포넌트 구조를 최대한 유지했습니다.
- 인증을 새로 도입하지 않고 제출 조건인 로그인 없는 접근을 유지했습니다.
