# TaskDiary 확인 방법

1. 어디로 가나요?
   - 첫 화면: 전체 대시보드
   - 계획: 왼쪽 `🎯 계획 세우기`
   - 할 일: 왼쪽 `📑 테이블 목록 관리`
   - 실행/완료 기록: 할 일 행을 펼친 뒤 `⏱ 실제로 한 일 기록`
   - 돌아보기: 왼쪽 `🔎 돌아보기`

2. 세 단계 안에 무엇을 하나요?
   - 계획: 계획 입력 → 기간/우선순위/성공 기준/예상 시간 입력 → 저장
   - 할 일: 제목/마감/우선순위/태그/예상 시간 입력 → 계획 연결 → 등록
   - 실행: 작업 펼치기 → 시작/종료/막힌 이유 입력 → 실행 기록 저장 또는 완료 기록

3. 무엇이 보이면 통과인가요?
   - 계획 수정 후 History에 수정 전 값이 남음
   - 검색/필터/정렬 기준이 화면에 표시되고 결과가 변함
   - 실행 기록의 시작/종료/실제 시간/막힌 이유가 DB에 남음
   - 완료 기록을 연속 클릭해도 동일 idempotency key로 1건만 생성됨
   - 돌아보기 수치 클릭 시 근거 작업이 표시됨
   - JSON Export 파일이 생성됨

4. 안 될 때는 무엇이 보이나요?
   - 계획/실행 기능에서 `DB 스키마를 확인하세요` 또는 저장 실패가 보이면 `supabase/001_pds_schema_v2.sql`을 Supabase SQL Editor에서 실행합니다.
   - 로그인 없는 공개 제출용이므로 실제 개인정보/비밀번호/Secret Key를 입력하지 않습니다.
